# Проверка Line 0.7.2 и API без Firebase

Дата: 2026-10-04. Основой остаётся присланный архив окончательной 0.6; собственная identity и pinning не сбрасываются.

## Реализовано и проверено

- Gradle: APK/test APK, JVM-тесты и Android Lint проходят. Конфликт Tink/Protobuf исправлен официальной substitution на Tink Android. Firebase Messaging удалён, Firebase Admin также отсутствует в package.json/lockfile API.
- 36 серверных тестов прошли: очередь ciphertext с atomic disk write, offline/restart/ACK/dedup/TTL/лимиты; публичное имя account-bound и сохранено при регистрации; свой/неизвестный номер; независимые admin-правила; push optional, endpoint allowlist, запрет private DNS, DNS-pinning и отсутствие redirects; удаление старых FCM-токенов без потери identity; офлайн-приглашение/room authorization/завершение.
- AOSP API 26: `publicProfileAndRecipientValidationUseAuthenticatedApi` — `OK (1 test)`, 9.892 секунды. Клиент отклоняет собственный и отсутствующий номер, получает имя чужого профиля и сохраняет собственное имя через authenticated pinned mock API. Это не соединение с VPS владельца.
- `UnifiedPushTest` — `OK (4 tests)`, 0.169 секунды: корректный формат HTTPS endpoint, отсутствие приватного URL в статусе, отсутствие crash при неустановленном дистрибьюторе. ntfy не был установлен в эмуляторе, поэтому доставка через дистрибьютор не считается проверенной.
- `UiFlowTest` — `OK (3 tests)`, 24.542 секунды: набор/удаление цифр, отдельный чат, просмотр версии, чистый профиль, графические статусы и удаление. Свежие снимки получены из Android; имена и сообщения на них — test fixtures, в app APK их нет.

## Что не утверждается

Нет доступа к работающему VPS владельца: API-пакет подготовлен, но не установлен там. Код-only обновление исключает данные/env/сертификаты/LiveKit. Перед установкой нужно определить фактическую API-службу/каталог, остановить только её на короткое время и сделать закрытую резервную копию JSON-хранилищ; инструкция не предлагает стирать данные 0.6.

Живой push через ntfy/UnifiedPush, реальные звонки двух физических телефонов, фактический звук и latency/FPS не проверены. Push требует установленного и работающего distributor и разрешённого сервером origin. Выключенный интернет, force-stop или ограничения батареи могут задержать/подавить доставку. «Офлайн-звонок» означает доставку приглашения отключённому клиенту, не аудио без сети.

Единичная галочка на старом API подтверждает передачу relay, а не прочтение. Двойная — сохранение получателем после decrypt; read receipts не реализованы. Очередь хранит E2EE ciphertext, но маршрутизационные метаданные и публичные имена остаются видимыми API. Имена не являются доказательством личности, SAS остаётся обязательной.

Новая APK-подпись проверяется относительно 0.7.1. Присланная 0.6 имеет другой ключ; uninstall/очистка данных пользователя не являются безопасным обходом. В Android-тестах очищались только disposable данные эмулятора.
