# NEXUS PROTOCOL

Web3 tiered staking & yield interface. Next.js 15 (App Router), strict TypeScript, Tailwind, Framer Motion, Zustand. Runs on an in-memory mock engine; no on-chain calls.

```
pnpm dev        # start
pnpm typecheck  # tsc --noEmit
pnpm build
```

Layout: `src/config` (protocol + tier schemas), `src/types` (domain types), `src/content` (legal copy), `src/lib` (helpers).
